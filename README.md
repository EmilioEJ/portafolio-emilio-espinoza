# Portafolio · Emilio Espinoza

Portafolio interactivo de Paulo Emilio Espinoza Jiménez, ingeniero en Tecnologías de la Información (Quito, Ecuador).

**En vivo:** https://portafolio-emilio-espinoza.vercel.app

## Qué tiene

- Escena 3D *Temple Night* en el inicio y animaciones de scroll con GSAP + ScrollTrigger.
- Proyectos en scroll horizontal, cada uno con una demo que se puede tocar: el avatar VRM de mi tesis, un mapa de calor de eyetracking, el flujo de altas en GLPI, un agente de IA, un probador de drift para mandos y un robot bípedo.
- Habilidades como iconos interactivos (Motion) con filtro por área.
- Un mapa de calor del propio visitante, calculado solo en su navegador.

## Stack

React 19 · Vite · TypeScript · Tailwind CSS v4 · GSAP · Motion · Three.js + @pixiv/three-vrm · ThreeUI · Rare UI (Fluid Orb) · react-icons

## Desarrollo

```bash
npm install
npm run dev
```

`npm run build` genera la versión de producción en `dist/`. Se despliega en Vercel.
